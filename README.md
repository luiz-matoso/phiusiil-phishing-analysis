# PhiUSIIL Phishing URL Analysis

Data Science project developed for the 2026/2 Data Science course at PUCPR.

## Task

Binary classification of URLs/websites as legitimate or phishing using the PhiUSIIL Phishing URL Dataset.

## Dataset

**PhiUSIIL Phishing URL Dataset**

Source: UCI Machine Learning Repository  
Dataset: https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset

The dataset contains features extracted from URLs and webpages that can be used to distinguish legitimate websites from phishing websites.

## Checkpoint

- Dataset definition
- Statistical description
- Univariate analysis
- Multivariate analysis
- Data visualization

Machine learning and validation will be developed after the checkpoint.
